# Four-theme visual contract

These four visual directions are the approved UI references for the Salon desktop app and are the source of truth for shell, cards, icons, spacing, hierarchy and color treatment.

1. **Noir Gold** — charcoal / matte black surfaces, restrained warm gold accents, premium salon feel.
2. **Ivory Copper** — warm ivory / beige surfaces, deep cocoa text, restrained copper accents, airy editorial feel.
3. **Emerald Graphite** — graphite / near-black surfaces, emerald accents, crisp modern operational dashboard feel.
4. **Rose Plum** — deep plum / burgundy surfaces, rose-gold accents, luxurious editorial feel.

Implementation rules:

- Keep business data and navigation/actions real; do not replace runtime data with mock values from concept art.
- Use icons as part of the information hierarchy (KPI cards, rows, actions), not as decoration pasted beside text.
- Avoid thick borders and nested cards. Prefer tonal separation, spacing, subtle shadows and controlled highlights.
- Preserve the same information architecture across all four themes while allowing theme-specific palette, glow, radius and typography character.
- New feature screens must use shared tokens/components instead of hard-coded colors.
